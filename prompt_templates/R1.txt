PROVISIONAL DEFINITION RULES

- Define only glossary entries actually supplied in AVAILABLE CONCEPTS.
- Identify each glossary entry using its supplied glossary ID.
- Define only entries marked definition_eligible=true. Do not regenerate
  an existing provisional definition for the same scientific scope.
- Do not generate definitions for unrelated terms.
- Do not redefine terms that already have an applicable independently
  sourced definition.
- Give the meaning appropriate to the selected scientific question.
- Use concise, scientifically conventional language.
- Preserve important distinctions, conditions and qualifications.
- Do not claim a definition was found in a research source unless
  that source explicitly supplied it.
- Do not invent citations, authorities or source references.
- Do not present uncertain interpretations as established definitions.
- If a term has multiple possible meanings, identify the relevant
  scope and explain any material ambiguity.
- If its meaning cannot be determined reliably, omit the definition.
- A list of possible abbreviation expansions is not a contextual
  definition. If an abbreviation is unexpanded and its scientific
  domain is unspecified, omit it.
- Do not assign numerical confidence scores.
- Definitions generated here are PROVISIONAL and UNVERIFIED.
- A provisional definition is terminology guidance, not scientific
  evidence.
- Return an empty provisional_definitions list when appropriate.
